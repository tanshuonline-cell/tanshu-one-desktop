# TANSHU ONE

**Independent, offline-first Windows desktop software** for photo studios, document work, PDF utilities, and CSC/cyber-cafe operations.

TANSHU ONE is a standalone product. It is not an extension of TANSHU ONLINE and must not depend on that website or its services.

## Product principles

- Offline-first: core editing and utility workflows work without an internet connection.
- Local-first privacy: user files and projects stay on the device unless a future feature clearly explains and obtains consent for an online operation.
- Windows 10 and Windows 11 target, with compatibility verified through testing.
- Original, premium interface with a clean light Photo Studio workspace and a distinct blue/cyan Home Dashboard.
- Clear separation between modules, projects, customer data, and settings.

- Utility Center

- Settings

## Explicit exclusions

TANSHU ONE will not include an Online Form Assistant, government-form filling or online-application automation, or a Bank/Government Information Hub. It will not integrate with TANSHU ONLINE for login, membership, payments, APIs, databases, storage, authentication, or runtime services.
