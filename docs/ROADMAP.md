- [x] Create a dedicated private GitHub repository.
- [x] Record product independence and initial scope.
- [x] Record proposed architecture and compatibility principles.
- [ ] Confirm technology stack with a minimal Windows desktop prototype.
- [ ] Establish coding standards, dependency policy, and issue templates.

## Phase 1 — Desktop shell

- [ ] Create the Tauri + React + TypeScript starter application (subject to Phase 0 validation).
- [ ] Build the Home Dashboard with the established blue/cyan direction.

- [ ] Implement local app-data paths and structured logging without sensitive content.
- [ ] Add basic automated checks and Windows build workflow.

## Phase 2 — Photo Studio MVP

- [ ] Light Photo Studio workspace with independent scrolling sidebars.
- [ ] Multi-page project model.
- [ ] Multi-layer image placement and selection.
- [ ] Move, crop, resize, rotate, opacity, duplicate, reorder, hide, and delete.
- [ ] Common page and print-size presets plus custom size.
- [ ] Save/reopen projects with assets preserved.
- [ ] PNG/JPEG export and print-size verification.

## Phase 3 — Core document tools

- [ ] PDF Master MVP.
- [ ] Image and file conversion/resizing tools.
- [ ] Document Studio basics.
- [ ] PVC & ID Studio with front/back layout and print sheet.

## Phase 4 — Business and public utilities

- [ ] Resume & Career.
- [ ] Invoice, receipt, quotation, and rate-list utilities.
- [ ] Cyber Cafe Manager operational records and slips.
- [ ] Education & Exam Desk.
- [ ] Banking & Financial calculators/utilities.
- [ ] Typing & Language and Utility Center.

## Phase 5 — Hardening and release

- [ ] Test on Windows 11 and a real Windows 10 environment.
- [ ] Test multi-DPI, printing, offline workflows, large files, and recovery.
- [ ] Review security, dependencies, licenses, and local data handling.
- [ ] Prepare signed installer, release notes, and update strategy.
- [ ] Run a limited pilot before general release.

## Release rule

Do not mark a feature complete until its main workflow, error states, offline behavior where applicable, and save/export behavior have been tested.
